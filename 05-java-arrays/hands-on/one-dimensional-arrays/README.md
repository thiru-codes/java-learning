# Hands-on: One-Dimensional Arrays

## 1. Find the Largest Element

Write a program that:

- Takes the number of elements and their values as input.
- Finds the largest element in the array.
- Prints the largest value.

**Goal:** Practice traversing an array and finding the maximum value.

## 2. Search for an Element

Write a program that:

- Takes an array of integers as input.
- Accepts another integer to search for.
- Checks whether the given element exists in the array.
- Prints its index if found, or an appropriate message if it is not found.

**Goal:** Practice searching and accessing array elements.

## 3. Basic Element Swap

Write a program that:

- Takes an array of integers as input.
- Accepts two valid indices from the user.
- Swaps the elements at those two indices.
- Prints the array after swapping.

**Goal:** Understand how to exchange array elements using a temporary variable.

## 4. In-Place Array Reversal

Write a program that:

- Takes an array of integers as input.
- Reverses the array without creating another array.
- Prints the reversed array.

**Goal:** Practice in-place array manipulation using two indices.

## 5. Reverse Elements at Even Indices

Write a program that:

- Takes an array of integers as input.
- Reverses only the elements located at even indices (`0, 2, 4, ...`).
- Keeps the elements at odd indices unchanged.
- Prints the resulting array.

**Example:**

```text
Input:  1 2 3 4 5 6 7
Output: 7 2 5 4 3 6 1
```

**Goal:** Practice selective array manipulation using index positions.

## 6. Swap the Minimum and Maximum Elements 

Write a program that:

- Takes the number of elements and their values as input.
- Finds the largest and smallest elements in the array, along with their respective indices.
- Swaps the largest and smallest elements using a separate `swap()` method.
- Prints the largest and smallest values before swapping.
- Prints the array after swapping.

**Goal:** Practice finding extreme values, tracking their indices, and implementing array operations using methods.
