# Assessment: Java Arrays

## 1. Vegetable Shop Inventory Management

Write a Java program that simulates a vegetable shop inventory system.

The program should:

- Collect the names and categories of at least 20 items from the consumer (e.g., fruits, vegetables, dairy products, etc.).
- Store the collected information in memory using arrays.
- Once the consumer completes the purchase, group the items by category.
- Display each category, the number of items belonging to it, and the names of those items.

**Goal:** Practice using arrays to store, organize, and process related data.

## 2. Sum of Array Elements

Write a program that:

- Creates and initializes a `double` array.
- Calculates the sum of all its elements.
- Prints the resulting sum.

**Goal:** Practice traversing an array and aggregating its values.

## 3. Matrix Addition

Write a program that:

- Declares and initializes two 2 × 2 matrices.
- Adds the corresponding elements of both matrices.
- Stores the results in a third matrix.
- Prints the resulting matrix.

**Goal:** Practice performing operations on two-dimensional arrays.

## 4. Find Diagonal Elements of a Matrix

Write a program that:

- Declares and initializes a 3 × 3 matrix.
- Prints the elements along its primary diagonal.
- Prints the elements along its secondary diagonal.

**Example:**

Given the matrix:

```text
1 2 3
4 5 6
7 8 9
```

Expected output:

```text
Primary diagonal: 1 5 9
Secondary diagonal: 3 5 7
```

**Goal:** Understand how to access specific elements in a two-dimensional array using row and column indices.
