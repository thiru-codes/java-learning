# Module 8: Exception Handling

## Topics

1. Differentiate among checked exceptions, unchecked exceptions, and Errors.
2. Create `try-catch` blocks and determine how exceptions alter normal program flow.
3. Create and invoke methods that throw exceptions.
4. Recognize common exception classes, such as `NullPointerException`, `ArithmeticException`, `ArrayIndexOutOfBoundsException`, and `ClassCastException`.
