# Hands-on: Common Exceptions

1. **Null Pointer Exception**

   Use a null object reference to understand when a `NullPointerException` occurs.

   File: `NullPointer.java`

2. **Class Cast Exception**

   Attempt to cast an object to an incompatible class and handle the resulting `ClassCastException`.

   File: `ClassCast.java`

3. **Array Index Out of Bounds Exception**

   Access an invalid array index and handle the resulting `ArrayIndexOutOfBoundsException`.

   File: `ArrayIndexOutOfBounds.java`

4. **Number Format Exception**

   Convert a String into an integer using `Integer.parseInt()` and handle invalid numeric input.

   File: `NumberFormatCheck.java`
