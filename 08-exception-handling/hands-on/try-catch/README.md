# Hands-on: Try-Catch

1. **Array Index Validation**

   Display an array, ask the user to enter an index, and print the value at that index. Handle an invalid index using `try-catch` and use `finally` to close the Scanner.

   File: `ArrayIndexValidation.java`

2. **Exception and Program Flow**

   Handle multiple exception types while withdrawing money from an account. Observe how an exception interrupts normal program execution and transfers control to the matching `catch` block.

   File: `ExceptionProgramFlow.java`
