# Hands-on: Exception Basics

## Exception Hierarchy

Review the Java exception hierarchy diagram to understand how `Throwable`, `Error`, and `Exception` are related.

The diagram includes examples of:

- **Errors:** `OutOfMemoryError`, `StackOverflowError`
- **Checked exceptions:** `IOException`, `ClassNotFoundException`, `SQLException`
- **Unchecked exceptions:** `NullPointerException`, `IllegalArgumentException`, `ClassCastException`, `ArrayIndexOutOfBoundsException`

Refer to `exception-hierarchy.png` for the hierarchy.
