# Module 6: Assessment

1. Create a class with a default constructor that displays a message when an object is created.

2. Create a class with instance variables and initialize them using a parameterized constructor. Display their values using a separate method.

3. Create a class that follows encapsulation principles by declaring its data members as private and providing public getter and setter methods to access and modify them.

4. Create a class with a static variable to count the number of objects created. Display the count using a static method.

5. Create a class with variables declared using different access modifiers (`private`, default, `protected`, and `public`). Inside a folder named `accessmodifier`, create another class in the same package and attempt to access these variables. Identify which variables are accessible.
