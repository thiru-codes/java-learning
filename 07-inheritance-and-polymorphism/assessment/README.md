# Assessment: Inheritance and Polymorphism

1. Collect your family hierarchy up to 7 levels deep and showcase the unique behaviour and common behaviour of each family member.

   (Family Hierarchy)

2. Create a base class and a derived class where the child class inherits properties and methods from the parent class. Demonstrate how inheritance helps in code reuse.

   (Basic Inheritance)

3. Create a parent class with a method and override that method in a child class. Call the method using a child class object and observe the overridden behaviour.

   (Method Overriding)

4. Create a parent class reference pointing to a child class object and call an overridden method. Explain the output based on runtime polymorphism.

   (Runtime Polymorphism)

5. Create an abstract class with both abstract and concrete methods. Extend this class in a child class and provide implementations for all abstract methods.

   (Abstract Classes)

6. Create an interface with multiple method declarations. Implement this interface in a class and demonstrate how interface-based references enable polymorphism.

   (Interfaces)

7. Create a multilevel inheritance hierarchy where methods are overridden at different levels. Use polymorphism to invoke methods and analyse the method resolution process.

   (Multilevel Inheritance)

8. Design a program where both an abstract class and an interface are used together. The abstract class should implement part of the behaviour while the interface defines additional capabilities. Extend and implement them in a concrete class.

   (Abstract Classes and Interfaces)
