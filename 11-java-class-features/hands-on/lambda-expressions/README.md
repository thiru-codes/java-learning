# Hands-on: Lambda Expressions

1. **Calculator Using Lambda Expressions**

   **Goal:** Understand lambda expressions and functional interfaces.

   **Task:**
   - Create a functional interface `MathOperation` with a method that accepts two integers and returns an integer.
   - Use lambda expressions to implement addition, subtraction, and multiplication.
   - Accept two numbers from the user.
   - Execute each operation using the corresponding functional interface reference and display the results.

   **File:** `Calculator.java`

2. **String Handling Using Lambda Expressions**

   **Goal:** Use lambda expressions to implement different String operations.

   **Task:**
   - Create a functional interface `StringOperation` with a method that accepts a String and returns a String.
   - Use lambda expressions to convert a String to uppercase, add a prefix, and reverse the String.
   - Accept a String from the user.
   - Execute each operation and display the results.
   - Use both single-expression and block-style lambda expressions.

   **File:** `StringHandling.java`
