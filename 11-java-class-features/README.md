# Module 11: Java Class Features

## Topics

1. Implement abstract classes and methods.
2. Apply the `final` keyword to classes, methods, and variables.
3. Create and use inner and nested classes, including static nested, member inner, local, and anonymous classes.
4. Create and use enums, including constructors, fields, and methods.
5. Declare and implement interfaces, extend interfaces, and use the `@Override` annotation.
6. Implement lambda expressions using functional interfaces.
