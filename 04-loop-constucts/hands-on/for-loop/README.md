# Hands-on: For Loop

## 1. Arrowhead Pattern

Write a program that takes an integer `n` as input and uses nested `for` loops to print an arrowhead pattern.

**Example for n = 4:**

```text
*
**
***
****
***
**
*
```

## 2. Multiples of a Number

Write a program that takes an integer as input and uses a `for` loop to print its multiples from 1 to 10.

**Example for input 5:**

```text
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
...
5 x 10 = 50
```

## 3. Peak Finder (Second Largest Number)

Write a program that:

- Asks the user how many numbers they want to enter.
- Reads that many integers one by one.
- Finds and prints the second-largest **distinct** number in the sequence.

**Example:**

```text
Input: 5, 9, 2, 9, 7
Largest: 9
Second largest: 7
```

**Goal:** Track two separate values—the largest and second-largest numbers—as new numbers are entered.

## 4. Reverse Digits

Write a program that takes an integer as input and reverses its digits, printing the result as a single integer rather than printing individual characters.

**Example:**

```text
Input: 4821
Output: 1284
```
