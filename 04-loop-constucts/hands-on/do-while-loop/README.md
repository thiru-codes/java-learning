# Hands-on: Do-While Loop

## 1. Countdown to Zero

Write a program that takes a positive integer as input and uses a `do-while` loop to count down to zero.

**Bonus:** If the user enters `0`, the program should print `0` immediately and stop.

## 2. Factorial Calculator

Write a program that takes a positive integer as input and calculates its factorial using a `do-while` loop.

## 3. Input Validator

Write a program that:

- Prompts the user to enter a number between 1 and 10 (inclusive).
- Uses a `do-while` loop to keep asking for input until the user enters a valid number.

## 4. Skip Multiples of 3

Write a program that uses a `do-while` loop to print all numbers from 1 to 20, excluding numbers that are multiples of 3.
