# Hands-on: While Loop

## 1. Print Even Numbers Up to N

Write a program that takes an integer `n` as input and uses a `while` loop to print all even numbers from 1 up to `n`.

## 2. Factorial Calculator

Write a program that takes a positive integer as input and calculates its factorial using a `while` loop.

## 3. Sum of Digits

Write a program that takes an integer as input and calculates the sum of its digits using a `while` loop.

## 4. Countdown Timer

Write a program that uses a `while` loop to count down from a given number of seconds to zero, printing each number along the way.
