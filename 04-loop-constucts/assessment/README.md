# Assessment: Loop Constructs

## 1. Sum Until User Enters 0 (`while`)

Write a program that:

- Continuously accepts integer input from the user.
- Stops when the user enters `0`.
- Prints the total sum of all entered numbers, excluding the terminating `0`.

**Goal:** Practice using `while` loops for input-controlled iteration.

## 2. Multiplication Table Using `for`

Write a program that:

- Takes a number as input (e.g., `5`).
- Uses a `for` loop to print its multiplication table.

**Example output for 5:**

```text
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
...
5 x 10 = 50
```

**Goal:** Practice controlled iteration using `for` loops.

## 3. Use `continue` to Skip Odd Numbers

Write a program that:

- Uses a `for` loop to iterate from 1 to 20.
- Uses `continue` to skip odd numbers.
- Prints only even numbers.

**Goal:** Understand how `continue` affects loop execution.

## 4. Use `break` to Stop at the First Prime Number Greater Than 10

Write a program that:

- Iterates through numbers starting from 2 up to 50.
- Finds the first prime number greater than 10.
- Uses `break` to terminate the loop once the number is found.

**Goal:** Understand conditional loop termination using `break`.

## 5. Nested Loops with `break` and `continue`

Write a program that:

- Uses nested `for` loops.
- Prints the following pattern:

```text
1 2 3
1 2
1
```

- Uses `break` to exit the inner loop.
- Uses `continue` where appropriate.

**Goal:** Practice controlling execution flow in nested loops using `break` and `continue`.
