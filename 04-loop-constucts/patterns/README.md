# Loop Patterns

A collection of Java pattern-printing exercises to practice nested loops, iteration, and output formatting.

All examples use an integer `n` as the pattern size.

## 1. Basic Patterns (`Patterns.java`)

### Pattern 1: Solid Square

**Example for n = 4:**

```text
****
****
****
****
```

### Pattern 2: Increasing Right-Angled Triangle

**Example for n = 4:**

```text
*
**
***
****
```

### Pattern 3: Decreasing Right-Angled Triangle

**Example for n = 4:**

```text
****
***
**
*
```

## 2. Intermediate Patterns (`IntermediatePatterns.java`)

### Pattern 1: Right-Aligned Increasing Triangle

**Example for n = 4:**

```text
   *
  **
 ***
****
```

### Pattern 2: Right-Aligned Decreasing Triangle

**Example for n = 4:**

```text

 ***
  **
```

### Pattern 3: Increasing Number Triangle

**Example for n = 4:**

```text
1
2 3

7 8 9 10
```

### Pattern 4: Pyramid Pattern

**Example for n = 4:**

```text
   *
  * *
 * * *
* * * *
```

## 3. Advanced Patterns (`AdvancedPatterns.java`)

### Pattern 1: Hollow Square

**Example for n = 5:**

### Number and Sequence Exercises

| File                 | Exercise                                       |
| -------------------- | ---------------------------------------------- |
| `Armstrong.java`     | Check whether a number is an Armstrong number. |
| `CountDigits.java`   | Count the number of digits in an integer.      |
| `Fibonacci.java`     | Generate the Fibonacci sequence.               |
| `Prime.java`         | Check whether a number is prime.               |
| `ReverseNumber.java` | Reverse the digits of an integer.              |
| `SumOfDigits.java`   | Calculate the sum of the digits of an integer. |
