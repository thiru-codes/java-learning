# Hands-on: Static Initialization and Nested Classes

1. **Configuration Initialization**

   **Goal:** Understand when a static initialization block runs and how it initializes static fields.

   **Task:**
   - Declare the static fields `environment` and `maxConnections`.
   - Initialize them inside a static initialization block.
   - Print the values from `main()` and observe the order of execution.

   File: `Configuration.java`

2. **Gaming System**

   **Goal:** Practice using static fields, a static initialization block, a static method, and a static nested class.

   **Task:**
   - Use a static field to track the number of created games.
   - Initialize the counter in a static initialization block.
   - Increment the counter when a `Game` object is created.
   - Access the nested `Helper` class and its methods.
   - Retrieve the game count using the static method.

   File: `GamingSystem.java`

   The Java files are arranged under `src/` according to their existing package declarations.
