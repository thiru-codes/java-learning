# Assessment Questions

## Question 1: Professional Details Management

Consider the following list of professionals:

- Cricketer
- Student
- Police
- Farmer
- Driver
- Engineer
- Family Man

Write a Java program to collect **7 identical details for each professional**, keep them in memory, consolidate the details, and present them in the console.

---

## Question 2: Variable Scope (Local vs Instance)

Write a Java program that:

- Declares an instance variable.
- Declares a local variable inside a method.
- Prints both values.

**Goal:** Understand where variables are accessible.

---

## Question 3: Basic Java Class Structure

Create a Java class that includes:

- One instance variable.
- One method that prints the variable's value.

**Goal:** Learn the basic structure of a Java class.

---

## Question 4: Main Method & Console Output

Write a Java program that:

- Contains a `main` method.
- Prints `"Hello, Java World!"` to the console.

**Goal:** Create an executable Java application.

---

## Question 5: Command Line Argument

Write a Java program that:

- Accepts a name from command-line arguments.
- Prints `Hello, <name>`.

**Example command:**

```bash
java Hello John
```

**Expected output:**

```text
Hello, John
```

**Goal:** Run a Java program using command-line arguments.

---

## Question 6: Block Scope Inside if Statement

Write a Java program that:

- Declares a variable inside an `if` block.
- Attempts to access it outside the block.
- Fixes the issue correctly.

**Goal:** Understand block-level scope.

---

## Question 7: Import a Java Package

Write a Java program that:

- Imports `java.util.Scanner`.
- Reads an integer from the console.
- Prints whether the number is even or odd.

**Goal:** Practice importing Java packages.

---

## Question 8: Static vs Instance Members

Create a Java class with:

- One static variable.
- One instance variable.
- A `main` method that prints both values.

**Goal:** Understand class-level vs object-level members.

---

## Question 9: Full Java Application Structure

Write a complete Java program that:

- Uses a package declaration.
- Imports the required packages.
- Defines a class.
- Contains a `main` method.
- Produces formatted console output.

**Goal:** Combine all structural elements of a Java application.

---

## Question 10: Encapsulation Example

Create a Java class that:

- Has private variables.
- Uses public getters and setters.
- Modifies and prints values using methods.

**Goal:** Demonstrate encapsulation in Java.

---

## Question 11: Java Features Comparison (Code + Explanation)

Write a Java program that:

- Demonstrates object orientation using a class and object.
- Demonstrates encapsulation using private fields.
- Prints messages explaining:
  - Platform independence.
  - Object orientation.

**Goal:** Connect Java features with actual code.
