# Import Java Packages — Questions

## Problem 1: The Automated Notepad

Create a single Java file named `Logger.java`.

### Goal

Write a program that automatically creates a file named `log.txt` on your computer and writes the sentence:

```text
Java basics are making sense!
```

inside it.

### What You Need to Practice

- Importing the correct `java.io` tools.
- Using a `try/catch` block to handle potential file errors.
- Writing code that compiles successfully while handling possible file-related exceptions.

## Problem 2: The Simple Clock

Create a single Java file named `Clock.java`.

### Goal

Write a program that fetches the current system date and prints only the 4-digit year to the console.

### What You Need to Practice

- Importing the correct `java.util` and `java.text` tools.
- Using a custom `SimpleDateFormat` pattern string to display only the year.
