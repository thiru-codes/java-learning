# Executable Java Program — Practice Question

## Problem 1: Favorite Color

Create a single Java file named `Greeter.java`.

### Task

Write a program that asks the user to enter their favorite color, then prints:

```text
Wow, [color] is a great color!
```

### What You Need to Practice

- Importing the correct tool for user input.
- Adding the `main` method so the program can run on its own.
- Compiling and running the program from the terminal.

### Goal

Practice taking user input, using the `main` method, and compiling and running a simple Java program from the command line.
