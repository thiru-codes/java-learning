# Class Structure — Practice Question

## Problem 1 — Bank Account

### Task

Create a Java class named `BankAccount` that manages information related to a bank and its accounts.

### Requirements

The class should track:

- The bank's name
- The total number of accounts created
- Unique account numbers
- Account balances
- Account types

The class must also include:

- A constructor to initialize a bank account
- A getter to retrieve the account balance
- A method to process a list of transaction amounts
