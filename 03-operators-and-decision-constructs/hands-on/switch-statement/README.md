# Switch Statement

## Question 1: Basic Calculator Using Switch

Write a method:

`public double calculate(double num1, double num2, char operator)`

Evaluate the `operator` variable using a `switch` statement:

- If `'+'`, return `num1 + num2`.
- If `'-'`, return `num1 - num2`.
- If `'*'`, return `num1 * num2`.
- If `'/'`, return `num1 / num2`.
- If it is any other character, print an error message and return `0.0`.
