# Assessment: Operators and Decision Constructs

## 1. Operator Precedence & Parentheses

Write a Java program that:

- Declares `int a = 10, b = 5, c = 2`.
- Prints the result of `a + b * c`.
- Prints the result of `(a + b) * c`.

**Goal:** Understand operator precedence and how parentheses override it.

## 2. String Equality (`==` vs `equals()`)

Write a program that:

- Creates two Strings using string literals (`"Java"`).
- Creates another String using `new String("Java")`.
- Compares them using `==` and `.equals()`.
- Prints the results.

**Goal:** Learn reference vs. content comparison for Strings.

## 3. if / else Condition

Write a program that:

- Takes an integer `age`.
- Prints `"Child"` if `age < 18`.
- Prints `"Adult"` otherwise.

**Goal:** Practice basic if / else.

## 4. switch Statement (Days of Week)

Write a program that:

- Uses `switch` on an integer (1–7).
- Prints the corresponding day name.

**Goal:** Practice switch syntax.

## 5. Object Equality Check

Write a program that:

- Creates two `Integer` objects with the same value.
- Compares them using `==` and `.equals()`.
- Prints both results.

**Goal:** Understand equality testing for objects.

## 6. Ternary Operator

Write a program that:

- Takes an integer `marks`.
- Uses a ternary operator to print `"Pass"` if `marks >= 40`, else `"Fail"`.

**Goal:** Practice ternary conditional logic.

## 7. switch with String

Write a program that:

- Uses a String variable `grade`.
- Uses `switch` to print messages for grades A, B, and C.
- Prints `"Invalid grade"` for other values.

**Goal:** Use switch with String.
