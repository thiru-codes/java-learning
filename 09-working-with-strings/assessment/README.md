# Assessment: Working with Strings

1. **String Analyzer**

   Write a program that:
   - Takes a sentence from the user.
   - Prints:
     - Total number of characters.
     - Total number of words.
     - Sentence in uppercase.
     - Sentence in lowercase.
   - Uses String class methods only.
   File: StringAnalyzer.java

2. **Order Summary Builder**

   Goal: Practice creating and modifying a mutable character sequence using StringBuilder.
   Task:
   - Create a StringBuilder with the heading Order Summary.
   - Append the customer name and two purchased items with their prices.
   - Insert a line showing the order ID before the customer details.
   - Replace the first item's name with an updated item name.
   - Remove a temporary note from the summary.
   - Print the final order summary.
   File: OrderSummaryBuilder.java

3. **Server Activity Log**

   Goal: Practice modifying a character sequence using StringBuffer.
   Task:
   - Create a StringBuffer to store server activity messages.
   - Append messages for server startup, a user login, and a user logout.
   - Insert a timestamp label at the beginning of the log.
   - Find the position of the user logout message using indexOf().
   - Replace the logout message with User session ended.
   - Print the final activity log.
   File: ServerActivityLog.java
