# Assessment Questions

## Question 1: Basic Calculator Operations

Write a Java program to perform basic calculator operations.

---

## Question 2: Character Validation

Write a Java program to check whether a given character is an alphabet or not.

---

## Question 3: Variable Declaration, Initialization & Casting

Write a Java program that:

- Declares an `int` variable with value `10`.
- Casts it to a `double`.
- Prints both values.

**Goal:** Practice primitive declaration and explicit casting.

---

## Question 4: Primitive vs Object Reference

Write a Java program that:

- Declares a primitive `int a = 5`.
- Declares an `Integer b = 5`.
- Changes `a` and `b` inside a method.
- Prints the values before and after the method call.

**Goal:** Understand how primitive variables and object references behave differently.

---

## Question 5: Read and Write Object Fields

Create a class `Student` with:

- Fields: `name` (`String`) and `marks` (`int`).
- Set values using an object.
- Read and print those values.

**Goal:** Practice accessing object fields.

---

## Question 6: Wrapper Class – Integer

Write a Java program that:

- Takes a `String` value `"123"`.
- Converts it into an `Integer`.
- Adds `10` to it and prints the result.

**Goal:** Practice `Integer` wrapper usage and parsing.

---

## Question 7: Object Lifecycle & Dereference

Write a Java program that:

- Creates an object of class `Book`.
- Assigns it to another reference.
- Sets the first reference to `null`.
- Prints values using the second reference.

**Goal:** Understand object lifecycle and dereferencing by reassignment.
